# 애드센스 채점기 2026.09.28

관리자 컴퓨터에서 공개 웹사이트를 읽기 전용으로 점검하고, 페이지별 근거가 담긴 한국어 HTML·PDF 보고서를 만드는 로컬 도구입니다. 빠른 표본 검사는 최대 20페이지, 기본 검사는 최대 200페이지이며, 관리자 전체 검사는 발견 가능한 공개 페이지를 대상으로 합니다. 자동 검사에는 유료 AI API를 사용하지 않습니다.

## 다운로드와 설치

소스코드와 ChatGPT 프로젝트용 v11 자료를 공개합니다. 누구나 다운로드하고 MIT 라이선스에 따라 사용·수정·재배포할 수 있습니다.

- [ZIP 다운로드](https://github.com/we-insub/adsense-auditor-2026/archive/refs/heads/main.zip)
- [GitHub 저장소](https://github.com/we-insub/adsense-auditor-2026)

```bash
git clone https://github.com/we-insub/adsense-auditor-2026.git
cd adsense-auditor-2026
```

ZIP으로 받았다면 압축을 푼 폴더에서 아래 설치 명령을 실행하세요. 소스만 다운로드해도 자동으로 실행되는 설치형 앱은 아닙니다.

## 준비

- macOS, Node.js 24, npm
- Google Chrome 또는 Playwright Chromium
- 사이트에 접근할 수 있는 인터넷 연결

```bash
npm ci
npx playwright install chromium
npm run dev
```

터미널에 표시되는 `http://127.0.0.1:4717` 주소를 **같은 컴퓨터**의 브라우저에서 여세요. 로그인 없이 바로 열립니다. 배포용 빌드는 `npm run build`, 실행은 `npm start`, 테스트는 `npm test`입니다. 검사 상태는 `~/Library/Application Support/AdSense Auditor/`의 파일에 저장되어 다시 실행해도 이어갈 수 있습니다.

## 검사 시작과 보고서 전달

1. 고객에게 [관리자 사용법](docs/사용법.md)의 공지 문구를 보내고 URL과 제외할 공개 경로를 받습니다. 접수 메시지는 관리자가 보관합니다.
2. 관리자 화면에서 URL을 입력하고 검사 범위를 선택합니다. 빠른 표본 검사는 최대 20페이지를 확인해 우선 문제를 살펴볼 때 사용하고, 기본 검사는 최대 200페이지를 검사합니다. 고객이 전체 검사를 맡긴 경우에만 관리자 전체 검사를 선택합니다.
3. 화면에서 발견·검사·실패 페이지 수와 진행 상태를 확인합니다. 필요한 경우 일시 중지했다가 재개합니다.
4. 완료 후 접근 실패, 확인 불가, 오탐이 의심되는 항목과 우선 수정 목록을 먼저 검토합니다.
5. 보고서를 미리 본 뒤 PDF로 내보내 고객에게 직접 전송합니다. HTML과 JSON은 관리자 재검토 자료로 보관합니다. 프로그램은 메시지나 이메일을 자동으로 보내지 않습니다.

보고서에는 검사한 범위의 자체 준비도 점수, **평가한 규칙 가중치와 확인하지 못한 가중치**, 영역별 점수, 페이지별 좋은 점·아쉬운 점·보완 이유·관찰 증거·수정 방법·근거 링크가 들어갑니다. 점수는 Google의 실제 AdSense 승인 확률이나 심사 결과가 아닙니다. 빠른 검사는 발견 수와 관계없이 20페이지 표본 결과임을 명시합니다. 200페이지가 넘는 사이트의 기본 검사에는 별도의 200페이지 표본 문구가 표시됩니다. 검색엔진 안내는 맨 아래에 있고 AdSense 점수에 반영되지 않습니다.

빠른 검사에 걸리는 시간도 페이지 응답 속도와 브라우저 렌더링에 따라 달라집니다. 20페이지 결과를 사이트 전체 또는 기본 200페이지 검사의 결과로 설명하지 마세요. 빠른 검사를 고객에게 제공할 경우 검사 범위를 미리 알리고, 보고서 전달문에 표시되는 빠른 표본 검사 문구를 함께 보내세요.

## 검사 범위와 해석

- 공개 `robots.txt`, 사이트맵, 내부 링크에서 발견 가능한 페이지를 검사합니다. 로그인 전용·숨겨진 페이지까지 전수 확인했다는 뜻은 아닙니다.
- 사이트맵이 없으면 내부 링크에서 발견한 범위만 검사합니다. 발견한 URL 수는 사이트 전체의 확정 페이지 수가 아닙니다.
- HTML과 렌더링 화면에서 미완성 문구, 빈 본문, 링크, 모바일 화면, 주요 정책·연락 정보 등을 확인합니다. 일반적인 `<input placeholder="검색어">`는 미완성 콘텐츠로 간주하지 않습니다.
- 접근 실패나 정책·계정 정보처럼 URL만으로 확인할 수 없는 내용은 별도로 표시합니다. 외부 저작물의 허가, 계정 중복·연령·결제·실제 심사 상태는 관리자와 고객이 확인해야 합니다.
- Google Search Console, Bing Webmaster Tools, 네이버 서치어드바이저의 등록·제출 여부는 공개 페이지만으로 확인할 수 없습니다. 보고서는 절차를 안내하며 색인이나 검색 노출을 보장하지 않습니다.

## 공개 소스와 검사 기록 관리

프로그램은 **각 사용자의 PC에서 127.0.0.1로** 실행합니다. 소스코드·검사 규칙·프로젝트용 프롬프트는 공개되어 열람·수정할 수 있습니다. 고객 사이트 검사 기록과 생성한 HTML·JSON·PDF는 공개 저장소에 포함하지 않습니다. 고객에게 검사 서비스를 제공한다면 검토한 PDF를 전달하고, 고객 자료가 담긴 개인 ChatGPT 프로젝트와 작업 장부는 비공개로 관리하세요. 로그인 화면이 없으므로 실행 중인 관리 화면을 외부에 공개하지 마세요.

로컬 채점 규칙 버전은 `2026.09.29-6`이며, 보고서에 검사일과 함께 기록됩니다. 규칙에서 Google 공식 정책·권장사항·채점기 자체 기준을 구분해 표시합니다.

자세한 고객 응대 문구와 단계별 사용법은 [관리자 사용법](docs/사용법.md)을 보세요.

## ChatGPT 프로젝트로 검사하기

로컬 프로그램 없이 ChatGPT 프로젝트만으로 검사하려면 [프로젝트 운영법](docs/ChatGPT-프로젝트-운영법-v11.md)을 따르세요. Sources에는 [전체 프로젝트 지침](docs/ChatGPT-프로젝트-지침-v11.txt), [검수기준](docs/ChatGPT-검수기준-v11.md), [운영법](docs/ChatGPT-프로젝트-운영법-v11.md), [보고서 스타일](docs/ChatGPT-보고서-스타일-v11.css), [PDF 수신 AI 판단 가이드](docs/ChatGPT-PDF-수신-AI-판단가이드-v11.md) **5개 파일만** 올립니다. URL만 입력하면 페이지 수와 빠른·정밀 방식을 선택합니다. ChatGPT Work에서 직접 HTTP/브라우저 접속을 시도하며, `Cache miss`만으로 사이트 장애를 판단하지 않습니다. 직접 확인 0건이면 수치형 성적 대신 원인·재검사 방법을 담은 진단 PDF를 만듭니다. 직접 확인했다면 실제 방문 N페이지의 **통합 X/100점**과 같은 숫자의 비공식 추정 지수 X%를 첫 장에 표시하고, 40/20/15/15/10 영역과 19개 규칙 배점의 기준표를 제공합니다. 고객 PDF에는 크리티컬·긴급·수정 필요 항목의 URL별 관찰·근거·수정 예시만 담고 양호 항목의 상세는 관리자 장부에 남깁니다. HTML/DOM을 실제 수집하지 못했다면 코드 상태를 추측하지 않습니다. 이 지수는 실제 승인 확률이나 계정 심사 상태가 아닙니다.
